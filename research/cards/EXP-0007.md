# EXP-0007：DreamerV3 共同 replay panel 多步 open-loop prediction 诊断

状态：`preregistered`，高成本运行：`not approved`，人工看图：`pending`。

## 一句话问题

在完全相同的冻结 replay observation/action 序列上，EXP-0006 的 baseline、E1、P4 checkpoint 是否呈现不同的多步世界模型预测能力，从而区分访问分布混杂、表征退化与 imagination drift？

## 阶段与基座

- 阶段：`exploration`
- 当前主要矛盾：把 EXP-0006 的低 KL、重构恶化和控制性能下降转化为共同数据支持上的功能性世界模型预测证据。
- Canonical baseline：`DV3-2026-DMCP-WALKER-KL-CONTROL`
- 模板：`probe`；证据权限：`diagnostic_only`
- 假说族：`dv3-kl-functional-prediction`；工作模式：`mixed`
- 唯一变量：冻结 checkpoint 的训练 arm：baseline、E1(no free bits)、P4-reconstructed(rep KL scale 1)，每臂 seeds 0/1。
- 预期动作：六个 checkpoint 在同一 576-window panel 上完成 16-step posterior warm-up 和 15-step real-action prior rollout，并产生 teacher/prior proprio、reward、KL 与 entropy 原始输出。
- 完成正向信号：六个 metadata 均绑定 exact step250000 checkpoint、同一 panel SHA256 与同一 clean runtime commit，且所有输出有限、row count 完整。；生成逐模型×来源×horizon 可复算 CSV、逐 window 尾部表、summary、RESULT 和主图。

## 假说

P4 相对 E1 将在两个配对训练 seed 中同时表现为更低的 posterior-prior KL 和更高的 horizon-15 prior proprio NRMSE；teacher-forced NRMSE 是否也恶化用于区分表征/decoder 退化与额外 rollout drift。E1 相对 baseline 方向开放。


## 替代解释

- P4 的训练 score/reconstruction 差异主要来自各策略访问分布不同；共同 panel 上预测差异会缩小或消失。
- 有限 16-step context、随机 latent draw 或 panel 标准差归一化会放大某一 arm 的误差。

## 控制项

- 六模型共享 panel、真实 action、context/horizon、评估 RNG、draw 数、batch、指标代码和 target normalization。
- 禁止读取 replay 缓存 dyn/deter 与 dyn/stoch；每窗无 episode boundary 且同 chunk 入选窗不重叠。

## 主指标

- 主指标：共同 panel pooled horizon-15 prior all-proprio NRMSE，按配对训练 seed 报告方向。
- 诊断指标：teacher-forced NRMSE、prior-teacher gap、reward error、posterior-prior KL/entropy、来源分层及 P95/max/worst window。
